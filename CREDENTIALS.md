## 📦 Функционал публичного каталога

### Публичная часть (без авторизации)
- **Страница каталога:** http://localhost:5173/catalog
- Просмотр категорий и товаров
- Детальный просмотр товара
- Форма заказа товара
- Форма обратной связи

### Админ-панель каталога (OWNER/MANAGER)
- **URL:** http://localhost:5173/catalog-management
- Управление категориями товаров:
  - Создание, редактирование, удаление
  - Настройка порядка отображения
  - Активация/деактивация
- Управление товарами:
  - CRUD операции
  - Загрузка изображений (URL)
  - Настройка цен и характеристик
  - Рекомендуемые товары
  - SEO-оптимизация (slug, meta-теги)
- Просмотр заказов с сайта
- Управление запросами обратной связи

## 🚀 Запуск системы

### Если сервисы не запущены:

1. **Backend:**
   ```bash

   npm run start:dev
   ```

2. **Frontend:**
   ```bash
   cd frontend
   npm run dev
   ```

### Проверка работоспособности:
- Backend: `curl http://localhost:3000/catalog-categories`

## 🔧 API Endpoints каталога

### Публичные (без авторизации):
- `GET /catalog-categories` - список категорий
- `GET /catalog-products` - список товаров
- `GET /catalog-products/:id` - товар по ID
- `GET /catalog-products/slug/:slug` - товар по slug
- `POST /catalog-orders` - создать заказ
- `POST /contact-requests` - отправить запрос обратной связи

### Защищённые (требуют авторизации OWNER/MANAGER):
- `POST /catalog-categories` - создать категорию
- `PATCH /catalog-categories/:id` - обновить категорию
- `DELETE /catalog-categories/:id` - удалить категорию
- `POST /catalog-products` - создать товар
- `PATCH /catalog-products/:id` - обновить товар
- `DELETE /catalog-products/:id` - удалить товар
- `GET /catalog-orders` - список заказов
- `GET /contact-requests` - список запросов
