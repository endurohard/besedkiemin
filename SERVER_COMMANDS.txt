ШАГ 3 (АЛЬТЕРНАТИВА): РУЧНОЕ РАЗВЕРТЫВАНИЕ
================================================

Если автоматический скрипт не работает, выполните вручную:

# 1. Установка Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
systemctl start docker
systemctl enable docker

# 2. Установка Docker Compose
curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 3. Установка Git (если нужно)
apt-get update && apt-get install -y git

# 4. Клонирование репозитория
cd /root
git clone https://github.com/endurohard/besedkiemin.git
cd besedkiemin
git checkout docker-deploy

# 5. Создание backend/.env
cat > backend/.env << 'EOF'
DATABASE_URL="postgresql://postgres:postgres@postgres:5432/besedki_emin?schema=public"
JWT_SECRET="your-super-secret-jwt-key-change-this-in-production"
JWT_EXPIRATION="7d"
TELEGRAM_BOT_TOKEN="your-telegram-bot-token"
TELEGRAM_BOT_USERNAME="besedkiemin_bot"
NODE_ENV="production"
PORT=3000
EOF

# 6. Создание frontend/.env
cat > frontend/.env << 'EOF'
VITE_API_URL=http://localhost/api
EOF

# 7. Запуск контейнеров
docker-compose up -d

# 8. Ожидание запуска БД (15 секунд)
sleep 15

# 9. Применение миграций
docker-compose exec backend npx prisma db push

# 10. Инициализация Kong
bash init-kong.sh

# 11. Проверка статуса
docker-compose ps

================================================
TROUBLESHOOTING
================================================

Проблема: Контейнер не запускается
Решение:
docker-compose logs [service_name]
docker-compose up -d --force-recreate [service_name]

Проблема: База данных недоступна
Решение:
docker-compose restart postgres
docker-compose logs postgres

Проблема: Kong не отвечает
Решение:
docker-compose logs kong
bash init-kong.sh

Проблема: Frontend показывает ошибки API
Решение:
- Проверьте frontend/.env (VITE_API_URL=http://localhost/api)
- Проверьте Kong: curl http://localhost:8001/
- Перезапустите frontend: docker-compose restart frontend
