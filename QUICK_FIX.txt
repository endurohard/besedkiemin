========================================
БЫСТРОЕ РЕШЕНИЕ ПРОБЛЕМЫ С ПОРТАМИ
========================================

ПРОБЛЕМА: Порт 443 занят другим контейнером Kong

========================================
РЕШЕНИЕ 1: Удалить старые Kong контейнеры (РЕКОМЕНДУЕТСЯ)
========================================

Выполните на сервере:

# Найти все контейнеры Kong
docker ps -a | grep kong

# Удалить все контейнеры Kong
docker ps -a | grep kong | awk '{print $1}' | xargs docker rm -f

# Или удалить конкретный контейнер по имени
docker rm -f kong_gateway

# Теперь запустить заново
cd /root/besedkiemin
docker-compose up -d

========================================
РЕШЕНИЕ 2: Остановить ВСЕ контейнеры и запустить заново
========================================

# Остановить все контейнеры
docker stop $(docker ps -aq)

# Удалить все контейнеры
docker rm $(docker ps -aq)

# Перейти в папку проекта и запустить
cd /root/besedkiemin
docker-compose up -d

========================================
РЕШЕНИЕ 3: Проверить, что занимает порты
========================================

# Проверить все запущенные контейнеры
docker ps -a

# Проверить что слушает порты 80, 443, 8001
netstat -tulpn | grep -E ":80|:443|:8001"

# ИЛИ
ss -tulpn | grep -E ":80|:443|:8001"

# ИЛИ (если установлен lsof)
lsof -i :80
lsof -i :443
lsof -i :8001

========================================
РЕШЕНИЕ 4: Изменить порты в docker-compose.yml
========================================

Если не хотите удалять существующие контейнеры,
можете изменить порты в docker-compose.yml:

nano /root/besedkiemin/docker-compose.yml

Найдите секцию kong и измените:
  ports:
    - "80:80"      -> "8080:80"
    - "443:443"    -> "8443:443"
    - "8001:8001"  -> "8001:8001"

Затем запустите:
docker-compose up -d

Приложение будет доступно на:
http://77.221.151.105:8080

========================================
ПОЛНАЯ ПЕРЕЗАГРУЗКА (если ничего не помогает)
========================================

# 1. Остановить все контейнеры
docker-compose down

# 2. Удалить все контейнеры
docker rm -f $(docker ps -aq)

# 3. Удалить все volumes (ОСТОРОЖНО! Удалит данные БД!)
docker volume rm $(docker volume ls -q)

# 4. Очистить систему
docker system prune -a -f

# 5. Запустить заново
cd /root/besedkiemin
docker-compose up -d

# 6. Применить миграции
sleep 15
docker-compose exec backend npx prisma db push

# 7. Настроить Kong
bash init-kong.sh

   ↓ если не помогло
