# 📞 Besedki EMIN SIP Phone

Desktop приложение для звонков через Yeastar S100 с прямым UDP SIP подключением.

## ✨ Особенности

- ✅ **Прямое UDP SIP подключение** на порт 5060
- ✅ Работает без WebSocket
- ✅ Поддержка входящих и исходящих звонков
- ✅ Простой и понятный интерфейс
- ✅ Кроссплатформенность (Windows, macOS, Linux)
- ✅ Автоматическая регистрация на Yeastar S100

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd electron-phone
npm install
```

### 2. Запуск в режиме разработки

```bash
npm start
```

### 3. Сборка приложения

```bash
# Для macOS
npm run build:mac

# Для Windows
npm run build:win

# Для Linux
npm run build:linux
```

## 📋 Настройка

При первом запуске введите:

1. **IP адрес Yeastar S100** - например `192.168.1.100`
2. **Extension** - ваш внутренний номер, например `1001`
3. **Пароль** - пароль от Extension
4. **Порт** - UDP порт SIP (по умолчанию `5060`)

Нажмите **"Подключиться (UDP)"**

## 🎯 Использование

### Исходящие звонки

1. Наберите номер на клавиатуре
2. Нажмите **"📞 Позвонить"**
3. Для завершения нажмите **"📞 Завершить"**

### Входящие звонки

1. При входящем звонке появится уведомление
2. Нажмите **"Ответить"** или **"Отклонить"**

## 🔧 Требования к Yeastar S100

### 1. Создать Extension

**Settings → PBX → Extensions**
- Создайте Extension (например, 1001)
- Установите пароль
- Включите UDP SIP регистрацию

### 2. Настроить Firewall

Убедитесь что открыты порты:
- **5060** - UDP SIP (регистрация и сигнализация)
- **10000-20000** - UDP RTP (аудио)

### 3. Проверить сеть

```bash
# Проверка доступности Yeastar
ping 192.168.1.100

# Проверка порта SIP
nc -zvu 192.168.1.100 5060
```

## 🏗️ Архитектура

```
Electron App (Desktop)
    ↓
JsSIP Library
    ↓
UDP SIP (Port 5060) → Yeastar S100
    ↓
RTP Audio (Ports 10000-20000)
```

## 🐛 Отладка

### Проблема: "Не удалось зарегистрироваться"

**Решения:**
1. Проверьте IP адрес Yeastar
2. Проверьте Extension и пароль
3. Убедитесь что Extension активен
4. Проверьте firewall

### Проблема: "Нет звука"

**Решения:**
1. Проверьте порты RTP (10000-20000)
2. Дайте разрешение микрофону в системе
3. Проверьте аудио устройства в системе

### Включить логи

В `main.js` раскомментируйте строку:
```javascript
mainWindow.webContents.openDevTools();
```

## 📦 Распространение

Собранное приложение будет в папке `dist/`:

- **macOS**: `Besedki EMIN Phone.dmg`
- **Windows**: `Besedki EMIN Phone Setup.exe`
- **Linux**: `Besedki EMIN Phone.AppImage`

## 🔐 Безопасность

- Пароли не сохраняются на диске
- Все соединения локальные (в пределах сети)
- UDP SIP без шифрования (добавьте TLS для защиты)

## 📝 Интеграция с веб-приложением

Приложение может получать команды от веб-приложения через:
1. HTTP API (запустите локальный сервер в Electron)
2. IPC через сокеты
3. Custom URL protocol (besedki://call/79991234567)
